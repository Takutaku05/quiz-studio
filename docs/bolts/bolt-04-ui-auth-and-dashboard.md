# Bolt 04: UI — Auth, Dashboard & CSV Upload Modal

## Scope
ログイン/新規登録画面（`/login`）、ダッシュボード画面（`/`）、およびCSVアップロードモーダルのUIを実装する。スマホ縦画面とPCブラウザの双方に対応したレスポンシブデザインとする。

## Requirements & Acceptance Criteria
1. **認証保護ルート & `/login` 画面**
   - 未ログインで `/` や `/quiz/:quizId` にアクセスすると `/login` へ遷移する。
   - サインイン / サインアップのモード切替、バリデーションエラー表示、ログイン成功後の `/` 遷移。
2. **ダッシュボード画面 (`/`)**
   - ログイン中ユーザーのメールアドレスとログアウトボタンを表示。
   - 登録済み問題集をカード一覧で表示（タイトル、問題数、作成日、「プレイ」ボタン、「削除」ボタン）。
   - 問題集が0件のとき空状態メッセージとアップロード導線を表示。
   - 「削除」操作で問題集が削除され一覧から消える（確認ダイアログ/確認UI付き）。
   - 「＋ 新規CSVアップロード」ボタンでモーダルを開く。
3. **CSVアップロードモーダル**
   - 問題集タイトル入力欄（ファイル選択時に拡張子 `.csv` を除いたファイル名を自動入力）。
   - ファイル選択インプットおよびドラッグ＆ドロップ領域。
   - バリデーションエラーがある場合は行番号と理由を一覧表示し、「保存」ボタンを無効化する。
   - 有効なCSVの場合は問題件数プレビューを表示し、「保存」で問題集を作成してモーダルを閉じ、ダッシュボード一覧に即時反映する。
