# Bolt 15: 「AIで問題集を作る」2ステップ導線（プロンプトコピー → 結果貼り付け画面遷移）

## Scope
`docs/requirements-chatgpt-import.md` に基づき、ChatGPT 連携のボタン配置と画面遷移を見直す。
1. ダッシュボードのボタン領域に **「AIで問題集を作る」** ボタンを追加する。
2. 「AIで問題集を作る」を押すと、まず **「ChatGPT用のプロンプトをコピー」** ボタンを中心としたステップ1画面を表示する。
3. 「ChatGPT用のプロンプトをコピー」ボタンが押されたら、プロンプトをクリップボードにコピーし、自動的に **結果を貼り付ける画面（ステップ2）** に移管（遷移）する。
4. **結果を貼り付ける画面の上部** に、コピーをミスした人・やり直したい人向けに **「ChatGPT用のプロンプトをコピー」** ボタンを配置する。

## Design Notes
- **AI問題集作成モーダルの分離と共通部品の抽出 (`src/components/AiQuizCreationModal.tsx`, `src/components/QuizImportShared.tsx`, `src/lib/useQuizPasteState.ts`, `src/lib/clipboard.ts`, `src/lib/useTransientFlag.ts`)**:
  - ダッシュボードの「AIで問題集を作る」から開く2ステップ専用モーダルとして `AiQuizCreationModal` を新設し、ファイルアップロード中心の `CsvUploadModal` とは責務を分離する（既存の `.csv` / `.xlsx` / `.json` アップロード・テンプレートガイド導線は `CsvUploadModal` 側で維持）。
  - テキスト貼り付け解析・クリップボード読取／書込・プロンプトプレビュー・バリデーションフィードバックは `useQuizPasteState` / `QuizImportShared` / `clipboard` / `useTransientFlag` に切り出して両モーダルで共有し、ロジック重複を排している。
- **2ステップ遷移とフォールバック設計**:
  - ステップ1（「プロンプトをコピー」画面）の「ChatGPT用のプロンプトをコピー」押下時に `CHATGPT_PROJECT_PROMPT` をクリップボードへコピーし、自動的にステップ2（「結果を貼り付け」画面）へ遷移して画面上部にコピー完了通知を表示する。
  - `navigator.clipboard.writeText` が失敗した場合でもステップ2へ自動遷移したうえで、上部のプロンプト本文手動コピー欄（`PromptPreviewBox`）と案内を自動展開する。
  - すでに生成結果を持っているユーザー向けのスキップ導線（「すでに生成結果をお持ちの場合はこちら（貼り付け画面へ進む）」）はクリップボードを上書きせずステップ2へ進む。
  - ステップ2の最上部（タイトル入力欄・貼り付け欄より上）に「ChatGPT用のプロンプトをコピー」再コピーバーを常設し、別のテキストを誤コピーした際にも戻らずワンタップで再コピーできる（成功時2秒間「コピーしました」表示、失敗時は手動コピー欄を展開）。

## Requirements & Acceptance Criteria
1. **ダッシュボードの「AIで問題集を作る」ボタン**
   - ダッシュボード上部のアクションボタン領域（および問題集0件時の空状態）に「AIで問題集を作る」ボタンを表示する。
   - 押下すると AI 問題集作成フローのステップ1（プロンプトコピー画面）が開く。
2. **ステップ1：プロンプトコピー画面 → ステップ2への自動遷移**
   - 「ChatGPT用のプロンプトをコピー」ボタンを表示する。
   - ボタン押下時に `CHATGPT_PROJECT_PROMPT` をクリップボードへコピーし、結果を貼り付ける画面（ステップ2）へ遷移する。
   - すでに結果を持っているユーザー向けに、そのまま貼り付け画面へ進めるスキップ導線も提供する。
3. **ステップ2：結果を貼り付ける画面（上部に再コピーボタン配置）**
   - 画面上部（タイトル入力欄・貼り付けエリアの上）に「ChatGPT用のプロンプトをコピー」ボタン（ミスった人用）を常設し、押下時にプロンプトを再コピーして完了フィードバック（「コピーしました」）を表示する。
   - 下部にはタイトル入力欄、「クリップボードから貼り付け」ボタン、JSON/CSV テキスト貼り付け欄、バリデーション結果表示、「保存」ボタンを配置する。
