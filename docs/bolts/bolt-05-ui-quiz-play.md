# Bolt 05: UI — Quiz Play Screen (Setup / Question / Result)

## Scope
クイズプレイ画面（`/quiz/:quizId`）の3つのフェーズ（設定・出題・リザルト）を実装する。モバイルでの片手操作を重視した大きめの選択肢タップ領域、進捗バー、一問一答/テストモードの切り替え、リザルト振り返りと誤答再挑戦を備える。

## Requirements & Acceptance Criteria
1. **存在しない / 他人の問題集アクセス時**
   - 該当問題集が見つからない場合、適切な案内とダッシュボードへ戻る導線を表示する。
2. **① 設定フェーズ**
   - 出題モード選択（一問一答モード / テストモード）。
   - 問題順シャッフル（ON/OFF）、選択肢シャッフル（ON/OFF）。
   - 「スタート」ボタンで出題フェーズへ遷移。
3. **② 出題フェーズ**
   - 進捗表示（例：`1 / 5`）とプログレスバー。
   - 問題文と、非空の選択肢（2〜4個）ボタンのみを表示（空の選択肢3・4は表示しない）。
   - **一問一答モード**: 選択肢クリック直後に正誤判定と解説を表示し、「次へ」（最終問題は「結果を見る」）ボタンを表示。
   - **テストモード**: 選択肢クリック時は正誤・解説を表示せず選択状態のみ示し、「次へ」（最終問題は「結果を見る」）ボタンで次へ進む。
4. **③ リザルトフェーズ**
   - 正答数・正答率（例：`4 / 5 (80%)`）を表示。
   - 全問振り返りリスト（問題文、自分の回答、正解、正誤表示、解説）を表示。
   - 「もう一度解く」（全問リスタート）、「間違えた問題だけ解く」（誤答がある場合のみ表示/有効）、「ダッシュボードへ戻る」ボタンを提供。
