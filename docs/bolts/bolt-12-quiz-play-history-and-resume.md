# Bolt 12: クイズプレイ画面の正誤記録・途中再開・出題対象

## Scope
`docs/requirements-review-and-resume.md` 3.1〜3.3 をクイズプレイ画面（`/quiz/:quizId`）に組み込む。

## Design Notes
- 画面差分を小さく保つため、設定画面の追加UIは `src/components/ResumeSessionCard.tsx` と `src/components/ReviewFilterSelector.tsx` に切り出す（未コミットのデザイン変更とのマージを楽にする）。
- **読み込み**: 問題集と同時に `listStats(userId, quizId)` と `getSession(userId, quizId)` を取得する。成績・セッションの取得失敗はプレイを妨げない（無いものとして扱う）。復元できないセッションは表示せず削除する。
- **出題対象**: 「すべての問題」「直近で間違えた問題」「正答率60%以下の問題」をラジオで選ぶ。各選択肢に該当件数を表示し、0件は非活性。
- **開始**: 「スタート」で選んだ対象・モード・シャッフルでセッションを作り、確認なしで `saveSession`（上書き）。
- **記録タイミング**: 一問一答は選択した瞬間、テストは「次へ / 結果を見る」押下時に `recordAnswer` と `saveSession`（`currentIndex` は次に進む位置）を呼ぶ。
- **完走**: リザルトへ遷移したら `deleteSession`。「もう一度解く」は全問題（`all`）、「間違えた問題だけ解く」は `retry_wrong` で新しいセッションを開始する。
- **再開**: 中断カード「中断中のセッションがあります」に `{出題対象・}{currentIndex+1} / {総数} 問目から・{モード}` を表示し、「続きから再開する」で同じ問題順・選択肢順・回答状況から再開する。`currentIndex` が総数以上（最終問題に答えた直後に離脱）の場合はリザルトへ進む。
- **保存失敗**: プレイは継続し、「学習記録を保存できませんでした」を控えめに表示する。リトライはしない。

## TDD Plan（`src/pages/QuizPlayPage.test.tsx` に追加）
1. 一問一答で回答すると、選択時点で成績が記録され、セッションが次の位置で保存される。
2. テストモードでは選択だけでは記録されず、「次へ」で記録される。
3. 完走するとセッションが削除される。
4. 中断後に画面を開き直すと中断カードが表示され、「続きから再開する」でシャッフル後の同じ問題・同じ回答状況から再開し、完走時の採点に再開前の回答も含まれる。
5. 中断中に「スタート」を押すと確認なしで新しいセッションに上書きされる。
6. 出題対象のバッジ件数と0件時の非活性、「直近で間違えた問題」で絞った出題。
7. 保存に失敗してもプレイが続き、警告が表示される。
8. 最終問題に答えた直後のセッションを再開するとリザルトが表示される。
